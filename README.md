# claude-code-statusline

A three-line status line for [Claude Code](https://code.claude.com) with a rotating tips line that teaches you a new command every 45 seconds.

```
▎ ◆ Opus 4.7 ✦ high  ┈  my-repo  ┈  main ✓ ↑2  ┈  ▰▰▰▰▰▱▱▱▱▱▱▱▱▱▱ 34% 68k/200k ⟳ 38%
▎ ⏱ 1h12m ◎ $4.20  ┈  ⚡ 23% 2h01m ↯ 41% 3d05h  ┈  ▲ 156 ▼ 23 +2 ~1  ┈  ⇄ #1234●
▎ ✧ /rewind  restore code or chat to an earlier checkpoint
```

## What it shows

**Line 1**

- Model with a tier icon (◆ Opus, ◇ Sonnet, ○ Haiku). The icon lights purple while extended thinking is on and dims when it is off.
- Effort chip (`✦ high`), colored by level.
- Current directory.
- Git branch with clean ✓ or dirty ✗ state, ahead ↑ and behind ↓ counts, and `@sha` for a detached HEAD.
- Context bar with a green to red gradient, tokens used out of the window, ⟐ when the last response exceeded 200k tokens, and ⟳ headroom left before auto-compact.

**Line 2**

- Session duration and cost.
- 5-hour ⚡ and 7-day ↯ rate limits with a countdown to reset.
- Lines added ▲ and removed ▼ this session, plus staged and unstaged file counts.
- Pull requests seen this session with their review state (✓ approved, ● pending, ✗ changes requested, ◌ draft).
- The task Claude is working on right now.

**Line 3**

- One tip from the pool, rotating every 45 seconds. A purple ✧ marks a curated tip. A green ✧ marks a tip mined from a recent Claude Code changelog or generated by Claude.

Every line adapts to the terminal width. The context bar wraps to its own row when line 1 is too long, and the rightmost clusters of line 2 drop first.

## Install

Requires Python 3.7+ and git.

```sh
git clone https://github.com/YoanWai/claude-code-statusline
cd claude-code-statusline
./install.sh
```

The installer copies `statusline.py` to `~/.claude/hooks/`, `refresh_tips.py` to `~/.claude/statusline-tips/`, seeds the tip pool, and points `statusLine` in `~/.claude/settings.json` at the script. Restart Claude Code to see it.

To wire it by hand instead, add this to `~/.claude/settings.json`:

```json
"statusLine": {
  "type": "command",
  "command": "python3 ~/.claude/hooks/statusline.py"
}
```

## Keeping the tips fresh

`refresh_tips.py` maintains `~/.claude/statusline-tips/pool.json`.

| Command | What it does |
| --- | --- |
| `refresh_tips.py` | Adds any missing curated tips and mines new commands and flags from the Claude Code CHANGELOG for every version it has not seen yet. |
| `refresh_tips.py --ai` | Asks headless `claude -p` for eight tips about lesser-known slash commands and adds the well-formed ones. Uses your Claude subscription. |

Schedule the refresh so new releases show up on their own. With cron:

```
0 9 * * *  python3 ~/.claude/statusline-tips/refresh_tips.py
15 9 * * 0 python3 ~/.claude/statusline-tips/refresh_tips.py --ai
```

Claude Code's `/schedule` command or a launchd agent on macOS work the same way.

Curated tips always stay. Changelog and AI tips are capped at 120, oldest first out.

## Configure

The knobs live at the top of `statusline.py`: bar width, truncation widths, tip rotation interval, cache TTLs, and the full color palette (Nord by default). Edit and save. Claude Code picks up the change on the next render.

## How it works

Claude Code pipes a JSON payload to the script on every render. The script reads model, cost, context, rate limit, and PR data straight from that payload, shells out to `git status` for branch state (cached for 0.8s), and reads the tip pool from disk. On Claude Code versions that omit `rate_limits`, it falls back to the usage API with the local OAuth token and caches the result for five minutes.

Tested on macOS. The Linux and WSL credential paths are in place and unverified. Windows is untested.
